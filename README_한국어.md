## 데이터

이 데이터는 풍력단지 A, B, C에 있는 풍력발전기 36대에서 수집한 SCADA 시계열 데이터 95개로 구성되며, 전체 기록 기간을 합하면 89년입니다.

풍력단지 A의 데이터는 [EDP 공개 데이터 플랫폼](https://www.edp.com/en/innovation/open-data/data)을 기반으로 하며, 포르투갈 육상 풍력단지의 발전기 5대에 대한 데이터입니다. SCADA 데이터와 특정 고장의 시작 시각을 정의한 고장 기록부에서 추출한 정보를 포함합니다. 이 자료 중 22개 데이터셋을 이 데이터 모음에 선정했습니다.

나머지 두 풍력단지는 독일의 해상 풍력단지입니다. 풍력단지 B와 C의 기밀 유지를 위해 세 단지의 데이터는 모두 익명화되었습니다.

README 원문에 따르면 95개 데이터셋 중 44개는 이상 이벤트가 표시되어 있고, 나머지 51개는 정상 동작을 나타냅니다. 각 데이터셋은 CSV 파일이며, 열은 특성, 행은 시계열 데이터의 각 시점을 나타냅니다.

> 번역자 주: 공개 데이터의 최신 설명에는 이상 이벤트 45개와 정상 이벤트 50개로 표시되어 있습니다. 이 파일은 원본 README의 숫자를 그대로 번역했으므로 분석 시 [제공자 안내](https://zenodo.org/records/15846963)와 실제 이벤트 정보를 함께 확인하세요.

각 풍력단지 `A`, `B`, `C`의 폴더 구조는 다음과 같습니다.

```text
Wind Farm <x>
├─ datasets
│  ├─ <event_id>.csv
│  └─ ...
├─ event_info.csv
└─ feature_description.csv
```

### 이벤트 데이터

`datasets` 폴더에는 데이터셋들이 있으며 각 데이터셋에는 예측 대상 이벤트가 하나 포함되어 있습니다. 각 CSV 파일은 풍력발전기 한 대의 시계열 데이터이며 학습 데이터와 예측 데이터를 모두 포함합니다.

데이터셋은 고차원 데이터로, 풍력단지에 따라 특성이 86개, 257개 또는 957개입니다. 예측 데이터에는 이벤트가 정확히 하나 있으며, 고장으로 이어지는 이상 이벤트이거나 정상 동작을 나타내는 정상 이벤트입니다.

특성은 센서 측정값의 10분 평균으로 제공됩니다. 일부 센서는 10분 동안의 최솟값, 최댓값, 표준편차도 제공합니다. 데이터셋에는 상태 ID(`status_type_id`), 설비 ID(`asset_id`), 시간(`time_stamp`), 행 ID(`id`)도 포함됩니다. 센서 데이터와 시간은 익명화되었습니다.

각 데이터셋 CSV에 포함되는 열은 다음과 같습니다.

- `time_stamp`: 10분 간격의 시간. 풍력단지의 정체를 알 수 없도록 익명화되었습니다.
- `asset_id`: 풍력발전기 ID. 같은 발전기에서 발생한 이벤트를 찾는 데 사용할 수 있습니다. ID 역시 익명화되었습니다.
- `id`: 각 시간에 부여된 추가 ID. 서로 다른 시간 형식으로 인한 혼동을 방지하기 위한 것입니다.
- `train_test`: 해당 시점이 데이터셋의 예측 데이터인지 학습 데이터인지 나타내는 문자열입니다.
- `status_type`: 해당 시점의 풍력발전기 상태입니다. 상태 ID는 6개이며, 0과 2를 정상 운전으로 간주합니다.
  - `0`: 정상 운전 — 정상적인 발전 모드
  - `1`: 출력 제한 운전 — 출력을 제한한 상태로 발전
  - `2`: 대기 운전 — 재가동을 기다리는 대기 상태
  - `3`: 정비 — 정비 모드 또는 정비팀이 현장에 있는 상태
  - `4`: 정지 — 고장 또는 다른 이유로 설비가 정지한 상태
  - `5`: 기타 — 그 밖의 운전 상태
- `sensor_x_avg`: 센서 측정값의 10분 평균
- `sensor_x_min`: 센서 측정값의 10분 최솟값(제공되는 경우)
- `sensor_x_max`: 센서 측정값의 10분 최댓값(제공되는 경우)
- `sensor_x_std`: 센서 측정값의 10분 표준편차(제공되는 경우)

> 원문에서 상태 열은 앞부분에는 `status_type_id`, 목록에는 `status_type`으로 표기되어 있습니다. 실제 CSV의 컬럼명을 확인하세요.

### 이벤트 정보

각 풍력단지에는 `datasets` 폴더의 모든 이벤트에 대한 추가 정보를 제공하는 이벤트 정보 CSV 파일이 있습니다. 이 파일에는 다음 열이 포함됩니다.

- `event_id`: 이벤트 ID
- `event_label`: 데이터셋의 이벤트가 이상 이벤트(`anomaly`)인지 정상 이벤트(`normal`)인지 나타내는 문자열
- `event_start`: 이벤트 시작 시각
- `event_end`: 이벤트 종료 시각
- `event_start_id`: 이벤트 시작 시각의 ID
- `event_end_id`: 이벤트 종료 시각의 ID
- `event_description`: 일부 이상 이벤트의 근본 원인에 대한 추가 정보

### 특성 설명

각 풍력단지의 서로 다른 특성들은 해당 풍력단지 폴더의 `feature_description` CSV 파일에 설명되어 있습니다. 이 파일에는 다음 열이 포함됩니다.

- `sensor_name`: 익명화된 센서 이름
- `statistic_type`: 센서 측정값이 10분 `평균`, `최솟값`, `최댓값`, `표준편차` 중 무엇인지 나타내는 문자열
- `description`: 센서 측정값에 대한 간단한 설명
- `unit`: 해당 센서의 단위
- `is_angle`: 센서가 각도를 나타내는지 여부를 나타내는 참/거짓 값
- `is_counter`: 센서가 누적 계수값을 나타내는지 여부를 나타내는 참/거짓 값
