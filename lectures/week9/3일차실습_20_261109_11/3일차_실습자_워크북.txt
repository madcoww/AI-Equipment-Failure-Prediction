3일차 실습자 워크북
주제: 설비 신호 해석, 센서 신뢰도, 데이터 출처와 손실

준비
- 03-01_유압·열설비_신호_계통태그목록.csv
- 03-01_유압·열설비_신호_유압운전.csv
- 03-01_유압·열설비_신호_가열로온도.csv
- 03-01_회전기계_태그목록_실습.csv (먼저 생성 스크립트 실행)
- 03-02_센서_고장_판별_이상구간샘플.csv
- 03-02_센서_고장_판별_정비알람이력.csv
- 03-02_데이터출처_메타데이터.csv 및 생성형 데이터
- 생성형 데이터는 03-02_데이터손실_실습데이터_생성.py로 준비

실습 1 | 회전기계 컬럼 매핑 (20분)
실행: 03-01_회전기계_태그목록_생성.py
분석 시작: 03-01_회전기계_컬럼매핑_실습.py
1. 모터 베어링 손상과 팬 불평형 각각의 주 신호, 확인 신호를 고른다.
2. 물리량, 단위, 방향/위치, 주기와 선택 이유를 표로 작성한다.
3. 모터 베어링 초기 손상은 요약 진동값만으로 한계가 있는지 설명한다.
4. 태그 목록에서 보유하지 않은 FAN 태그를 찾고 요청 우선순위를 매긴다.

실습 2 | 유압·열설비 데이터 해석 (25분)
분석 시작: 03-01_유압_열설비_신호_실습.py
1. 유압 첫 30일과 마지막 10일 평균을 비교한다.
2. 필터 차압(전단-후단)을 계산해 1~30, 31~60, 61~90일의 증가폭을 비교한다.
3. 가열로 각 존의 우측-좌측 편차를 1, 20, 40, 60일에 비교한다.
4. Z2 편차의 위치별 원인 후보와 45일 전후 소재 온도/속도 변화의 관계를 설명한다.

실습 3 | 센서 이상 구간 판별 (30분)
분석 시작: 03-02_센서_고장_판별_실습.py
1. 모터 계통 또는 유압·가열로 계통을 선택한다.
2. 결측, 연속 반복, 최대값 반복, 변동 폭의 변화를 수치로 찾는다.
3. 가동 상태, 관련 신호, 정비·알람 이력을 교차 확인한다.
4. 각 후보를 설비 이상/센서 이상/판단 보류로 분류하고 유형, 구간, 근거를 기록한다.
5. 판단 보류에는 필요한 추가 신호·기록과 임시 처리(원본 유지, 학습 제외 등)를 적는다.

실습 4 | 데이터 출처와 정보 손실 (20분)
먼저 실행: 03-02_데이터손실_실습데이터_생성.py
분석 시작: 03-02_데이터_출처와_손실_실습.py
1. 원본과 가공본의 행 수·주기·최댓값·고유값 수를 비교한다.
2. 압력 원본의 짧은 서지가 1분 평균에서 어떻게 달라지는지 찾는다.
3. 온도 5분 집계와 데드밴드가 짧은 변화를 어떻게 지우는지 설명한다.
4. 데이터 제공자에게 물을 출처, 원래 주기, 집계법, 데드밴드, 품질 코드 및 강제 저장 항목을 정리한다.
